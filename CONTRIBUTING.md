## What to submit

Submit useful code, original authorized assets, a documentation improvement, a reproducible test report, or a factual record of your actual creative work. Keep changes focused, explain AI assistance accurately and report only checks you performed. Follow [LICENSE](LICENSE) and [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md); do not upload credentials, private conversations or unlicensed reference assets.

Preserve the existing credits and their order. A name-only file, an empty commit or fabricated authorship is not a substitute for a contribution.

## Send and verify

1. Work on a branch in your own fork.
2. Open [Compare](https://github.com/shian493719730-art/italia_uno/compare), choose **compare across forks**, then select this repository's `main` as the base and your fork branch as the head.
3. Review the diff, describe the actual work and create the pull request.
4. Send the maintainer the resulting URL. It must begin with `https://github.com/shian493719730-art/italia_uno/pull/`.

A PR proposes changes; the maintainer reviews and decides whether to merge. Opening a PR does not grant write access. GitHub's Contributors graph uses qualifying commits on the default branch and linked author emails; it is separate from README credits and cannot be manually ordered. See [GitHub's contributor guidance](https://docs.github.com/en/repositories/viewing-activity-and-data-for-your-repository/viewing-a-projects-contributors).
